# FSMPBank — банковская система для F-SMP

Плагин на **Paper** (Java 21): личные счета, карты, переводы, покупки,
корпоративные счета (ИП) и роль банкира-«банкомата».

**Валюта — АР (алмазная руда).** Это физический предмет (`DIAMOND_ORE`):
банкомат реально принимает и выдаёт алмазную руду из инвентаря. 1 АР = 1 предмет.

**Всё делается через UI.** Открыл `/bank` — и дальше только клики: перевод,
банкомат, ИП, история, а если выдана роль — окно банкира и админ-панель.
Команды остаются как быстрый доступ, но не обязательны.

---

## Возможности

- **Личный счёт** — по одному на игрока, открывается кнопкой в меню.
- **До трёх карт** на счёт — карта это отдельный номер, деньги списываются
  с привязанного счёта.
- **Переводы и покупки** — через UI: голова онлайн-игрока или ввод номера
  счёта, затем выбор суммы кнопками.
- **Банкомат** — внести/снять АР (алмазную руду): предметы физически уходят
  из инвентаря на счёт и обратно.
- **Корпоративные счета (ИП)** — открытие, пополнение/снятие и управление
  сотрудниками из меню; приём оплаты по номеру счёта или через табличку.
- **Платёжные таблички** `[Bank]` — клик открывает окно оплаты.
- **Банкиры (кассы)** — назначаются админом, через своё окно пополняют и
  снимают средства игрокам.
- **Админ-панель в UI** — назначение банкиров и установка баланса кликами.
- Автосохранение раз в 5 минут + сохранение при выключении сервера.
- Все данные — в `plugins/FSMPBank/data.yml`, все тексты и настройки — в `config.yml`.

## Сборка

> ⚠️ Версия Minecraft. В задаче указана `26.1.2`, официальной версии с таким
> номером на момент написания не существует (актуальная линейка — `1.21.x`).
> Плагин написан на стабильном Paper API и не использует «свежих» методов,
> поэтому работает на широком диапазоне версий. Перед сборкой поставь в
> `pom.xml` (свойство `paper.api.version`) артефакт `paper-api`, точно
> совпадающий с твоим ядром, и при необходимости поправь `api-version` в
> `src/main/resources/plugin.yml`.

```bash
mvn clean package
```

Готовый `FSMPBank-1.1.0.jar` появится в папке `target/`. Положи его в `plugins/`.

## Команды

### Игрок — `/bank` (алиасы: `/b`, `/банк`)

| Команда | Действие |
|---|---|
| `/bank` | открыть меню банка |
| `/bank open` | открыть счёт |
| `/bank balance` | баланс личного и корпоративных счетов |
| `/bank card` | список карт |
| `/bank card new` | выпустить карту (до лимита) |
| `/bank card remove <номер>` | удалить карту |
| `/bank pay <игрок\|счёт\|карта> <сумма>` | перевод / оплата |
| `/bank corp create <название>` | открыть ИП |
| `/bank corp list` | список своих ИП |
| `/bank corp info <счёт>` | информация об ИП |
| `/bank corp deposit <счёт> <сумма>` | внести деньги на ИП со своего счёта |
| `/bank corp withdraw <счёт> <сумма>` | снять деньги с ИП на свой счёт |
| `/bank corp addmember <счёт> <игрок>` | добавить сотрудника |
| `/bank corp removemember <счёт> <игрок>` | убрать сотрудника |
| `/bank history [счёт]` | последние операции |

### Банкир (банкомат)

| Команда | Действие |
|---|---|
| `/bank deposit <игрок> <сумма>` | зачислить наличные на счёт игрока |
| `/bank withdraw <игрок> <сумма>` | списать наличные со счёта игрока |

### Админ — `/bankadmin` (алиас `/ba`)

| Команда | Действие |
|---|---|
| `/bankadmin addbanker <игрок>` | назначить банкира |
| `/bankadmin removebanker <игрок>` | снять банкира |
| `/bankadmin listbankers` | список банкиров |
| `/bankadmin setbalance <игрок\|счёт> <сумма>` | задать баланс |
| `/bankadmin info <игрок\|счёт>` | информация о счёте |
| `/bankadmin reload` | перезагрузить конфиг |

## Платёжные таблички-терминалы

Поставь табличку и напиши:

```
[Bank]            ← строка 1: заголовок (настраивается в config.yml)
1234567890        ← строка 2: номер счёта-получателя (личный или ИП)
250               ← строка 3: сумма (пусто = покупатель выбирает сам)
Магазин брони     ← строка 4: назначение (необязательно)
```

Любой игрок кликает по табличке → открывается окно оплаты. Если сумма не
задана — покупатель выбирает её кнопками, затем «Оплатить». Деньги уходят
с личного счёта покупателя на указанный счёт. Так делается и приём оплаты
на ИП, и обычная касса магазина.

## Права

| Право | По умолчанию | Что даёт |
|---|---|---|
| `fsmpbank.use` | все | базовый доступ к банку |
| `fsmpbank.sign.create` | все | создание платёжных табличек |
| `fsmpbank.corp.create` | все | открытие ИП |
| `fsmpbank.banker` | op | роль банкира (банкомат) |
| `fsmpbank.admin` | op | администрирование банка |

Обычно роль банкира выдаётся не пермишеном, а командой
`/bankadmin addbanker <игрок>` — так админ назначает конкретных игроков-кассиров.

## Настройка

Все параметры (валюта, лимит карт, комиссия за перевод, размер истории,
стоимость открытия ИП, тексты сообщений) — в `config.yml`. После изменений:
`/bankadmin reload`.
